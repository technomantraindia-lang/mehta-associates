## 📁 Repository Structure

```
├── assets/             # Brand logos, photography, and certificate imagery
├── css/
│   ├── style.css       # Core corporate design system & responsive UI
│   ├── responsive.css  # Tablet and mobile breakpoints
│   └── animations.css  # Micro-animations and tickers
├── js/
│   ├── main.js         # Site-wide interactive logic, navigation & back-to-top
│   └── products.js     # Dynamic catalogue filtering & search
├── data/
│   └── products.json   # Full indexed catalog of pharmaceutical raw materials
├── documents/          # Official company brochure and technical downloads
├── index.html          # Homepage with Hero, Bento grid, & Interactive Showcase
├── products.html       # Product Catalogue with live search & domain filters
├── about.html          # 40-year legacy, founder timeline, and compliance standards
├── contact.html        # Direct trading desks, Mumbai HQ map, and quote inquiry
└── serve.js            # Lightweight local preview static server
```

## 💻 Local Preview

Run using Node.js:
```bash
node serve.js
```
Then visit `http://localhost:3000` in your web browser.
